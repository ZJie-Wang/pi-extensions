# lazygit

Open [lazygit](https://github.com/jesseduffield/lazygit) without leaving pi.

`/lazygit` and `ctrl+alt+l` hand the terminal to lazygit in the current directory. When lazygit exits, pi comes back. It runs only in interactive TUI mode and waits for the current agent run to finish. The `lazygit` binary must be on your `PATH`.
